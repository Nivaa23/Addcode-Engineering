# ADDCODE Engineering Website

A modern, high-end, Framer-inspired corporate website for **ADDCODE Engineering Pvt Ltd**, an industrial engineering design firm. This project emphasizes technical credibility, multidisciplinary mastery, and a professional B2B conversion-oriented experience.

## ✨ Features
- **Premium Bento Grid Layout**: Modern, asymmetrical industry sectors presentation with high-quality cinematic imagery.
- **Micro-interactions**: Smooth scroll reveals, dynamic header effects, and Framer-style animations.
- **Multidisciplinary Service Architecture**: Dedicated sub-pages for Piping, Process, Instrumentation, Electrical, and more.
- **Zendesk-Inspired Footer**: High-end dark theme footer with structured navigation and primary CTA prominence.
- **Interactive Hero Sections**: Canvas-based dynamic background effects for a futuristic engineering aesthetic.

## 📄 Pages Included
### Core Pages
- `index.html`: Corporate landing page with value propositions and high-level stats.
- `about.html`: Detailed company history, vision, and core values.
- `services.html`: Central hub for all engineering disciplines.
- `industries.html`: Advanced bento-grid showcase of market specializations (Oil & Gas, Petrochemical, etc.).
- `contact.html`: Direct engineering access portal with a focused inquiry-centric design.
- `proposal.html`: Dedicated high-end project engagement form.
- `why-addcode.html`: Value differentiation and trust-building overview.

### Service Sub-Pages (`/services`)
- `piping.html`: Advanced Piping Engineering & 3D Modelling.
- `process.html`: High-precision Process Design & Simulation.
- `instrumentation.html`: Data-centric Instrumentation systems.
- `electrical.html`: Resilient Power Distribution solutions.
- `civil.html`: Civil & Structural foundations.
- `mechanical.html`: Static & Rotating equipment expertise.
- `pipeline.html`: Cross-country transport infrastructure.
- `hse.html`: Health, Safety, and Environment engineering.
- `miscellaneous.html`: Technical data support and asset digitization.

## 🛠️ Technologies Used
- **Frontend**: Semantic HTML5, Vanilla JavaScript.
- **Styling**: Vanilla CSS3 (Modern Flex/Grid, CSS Variables, Custom Transitions).
- **Icons**: [Lucide Icons](https://lucide.dev/) (via CDN).
- **Typography**: Inter (Google Fonts).

## 🚀 How to Run Locally
1. Clone this repository or download the source code folder.
2. Ensure you have a local development server running (like Live Server for VS Code) to handle the relative path routing correctly.
3. Open `index.html` in your browser.
